1. 실험 설계 개요

본 실험은 순수 집단 간 설계(Between-subjects)를 채택한다. 두 집단에 서로 다른 읽기 보조 조건을 부여하고, 즉시 및 지연 이해도 퀴즈 점수로 효과를 비교한다.

독립변수 (IV)

집단읽기 조건조작 내용
A그룹 (n=15)
AI 요약 조건		 AI 요약문 제공 후 읽기 논문 읽기 전/중에 AI가 생성한 핵심 요약문을 참고할 수 있음. 수동적 정보 수용.
B그룹 (n=15)
개념도 조건		 지식 구조화 캔버스 사용 논문을 읽으면서 직접 키워드와 관계를 노드-엣지 형태로 구성. 능동적 지식 내재화.

종속변수 (DV)

  • 즉시 이해도 퀴즈 점수 (T1): 읽기 직후 측정
  • 지연 이해도 퀴즈 점수 (T2): 24시간 후 측정 — 장기 파지(retention) 반영
  • 판단 확신도: 1–5 Likert, 문항별 측정
  • 설문 리커트 점수: 주관적 유용성·부담감

2. 최소 표본 수 결정

CLT 기준 정규분포 가정

중심극한정리(CLT)에 의해 집단 내 n ≥ 30이면 표본 평균 분포가 정규분포에 근사한다. 그러나 독립 t-검정에서 집단 내 정규성을 따로 확인하므로 집단당 최소 15명이 실질적 권고 하한선이다.

검정력 분석 (G*Power: 독립 t-검정 기준)

  • 유의수준 α = 0.05 (양측)
  • 목표 검정력 1−β = 0.80
  • 효과 크기 Cohen's d = 0.50 (중간 효과, 인지·교육 분야 관례)
  • 집단 수 = 2 (동등 집단 크기)
n=10/집단 (총 20)검정력 ≈ 0.46
n=15/집단 (총 30) ← 최소 채택검정력 ≈ 0.62
n=20/집단 (총 40) ← 권장검정력 ≈ 0.80
n=26/집단 (총 52)검정력 ≈ 0.92

탈락·결측 대비 10~15% 여유를 두어 집단당 17명, 총 34명 모집을 권장한다. 시스템 번호 체계: 01~17 = A그룹, 18~34 = B그룹, 또는 홀수=A그룹, 짝수=B그룹.

3. 귀무가설 및 대립가설

종속변수는 이해도 퀴즈 정답률(%)이다: score(%) = (획득점수 / 최대점수) × 100

핵심 비교 지표: 즉시 퀴즈(T1) 및 지연 퀴즈(T2) 점수 집단 간 차이.

H1 — 즉시 이해도: 개념도 vs AI 요약

귀무가설 H0₁
즉시 퀴즈 점수: 집단 간 차이 없음

μT1,B = μT1,A
개념도 조건과 AI 요약 조건 간 즉시 이해도 퀴즈 점수에 유의한 차이가 없다.

대립가설 H1₁ 핵심
개념도 집단의 즉시 점수가 더 높음

μT1,B > μT1,A
능동적 지식 구조화가 수동적 AI 요약 읽기보다 즉각적 이해를 촉진한다.

H2 — 장기 파지: 24시간 후 보유율 (핵심 가설)

귀무가설 H0₂ 핵심
지연 퀴즈 점수: 집단 간 차이 없음

μT2,B = μT2,A
24시간 후 장기 파지 점수에 집단 간 유의한 차이가 없다.

대립가설 H1₂
개념도 집단의 지연 점수가 더 높음

μT2,B > μT2,A
능동적 지식 구조화는 AI 요약 읽기보다 장기 기억 파지에 유리하다.

H3 — 파지율 감소폭: 망각 속도 비교 (탐색적)

귀무가설 H0₃
T1→T2 점수 감소폭: 집단 간 차이 없음

(μT1,B − μT2,B) = (μT1,A − μT2,A)
두 집단의 망각 속도(파지율 감소)에 유의한 차이가 없다.

대립가설 H1₃
개념도 집단의 망각이 더 느림

ΔB < ΔA  (Δ = T1 − T2)
개념도 조건이 AI 요약 조건보다 망각이 적다.

H4 — 개념도 복잡도와 학습 효과 (탐색적, B그룹 한정)

귀무가설 H0₄
개념도 정교성과 퀴즈 점수 무상관

ρ(노드 수, T2) = 0
개념도를 더 정교하게 구성했더라도 지연 퀴즈 점수와 관련이 없다.

대립가설 H1₄
복잡도↑ → 지연 점수↑

ρ(노드 수, T2) > 0
정교한 개념도를 구성한 참가자일수록 장기 파지 점수가 높다.

4. 유의수준 설정

가설검정 방법유의수준 α방향근거
H0₁ (즉시 이해도) 독립 t-검정 0.025 단측 방향성 명확 (개념도 > AI 요약), Bonferroni 2개 주 가설 교정
H0₂ (지연 파지) 독립 t-검정 0.025 단측 핵심 가설, 동일 교정
H0₃ (망각 속도) 독립 t-검정 0.05 단측 탐색적, 교정 미적용
H0₄ (복잡도 상관) Pearson/Spearman r 0.05 양측 탐색적, B그룹 단독
반복 측정 보조 분석 대응 t-검정 (각 집단 내) 0.05 단측 T1→T2 변화 확인 (집단 내)
Bonferroni 교정 적용 범위: 주요 가설 H0₁과 H0₂는 동일 참가자에서 수집된 두 측정치를 각각 검정하므로 패밀리와이즈 오류율 제어를 위해 α = 0.05/2 = 0.025를 적용한다. 탐색적 가설(H0₃, H0₄)은 교정 없이 α = 0.05를 유지하고 결과 해석 시 탐색적 성격임을 명시한다.

5. 정량화 지표 및 측정 변수

주요 종속변수 (Primary DVs)

T1_rate(%) = (즉시 퀴즈 점수 / 최대 점수) × 100
T2_rate(%) = (지연 퀴즈 점수 / 최대 점수) × 100

retention_drop = T1_rate − T2_rate   ← 망각량 (작을수록 파지 우수)
retention_ratio = T2_rate / T1_rate × 100   ← 파지율 (높을수록 우수)

퀴즈 구성 (예시)

문항 유형수점수설명
재인 (Recognition) 4문항 4점 4지 선다형, 논문 핵심 개념 확인
회상 (Recall) 3문항 0–9점 단답/서술, 루브릭 채점 (0–3점/문항)
적용 (Application) 1문항 0–3점 논문 개념을 새로운 맥락에 적용
합계 8문항 16점 만점 T1, T2 동일 문항 또는 동형 문항 사용
T1/T2 동일 vs 동형 문항: 동일 문항을 쓰면 기억 연습 효과(testing effect)로 T2 점수가 올라가는 편향이 생긴다. 가능하면 동형 문항(parallel forms)을 구성하는 것이 이상적이다. 시간 제약이 있으면 동일 문항을 쓰되 이 한계점을 논문에 명시한다.

보조 측정변수 (Secondary DVs)

변수측정 방법분석 목적
판단 확신도 (confidence) 1–5 Likert, 문항별 Overconfidence index — 자동화 편향 탐색
설문 리커트 5점 Likert × 5문항 (집단별 맞춤) 주관적 유용성·부담감 기술통계
개념도 복잡도 (B그룹) 노드 수, 엣지 수, 수정 횟수, 소요 시간 T2 점수와의 상관 (H0₄)
읽기 소요 시간 논문 읽기 시작 ~ 완료 버튼 클릭 집단 간 읽기 시간 균형 확인 (혼입 검증)

6. 통계 검증 방법 (분석 순서)

1
기술통계 (Descriptive Statistics)

집단별 T1/T2 score_rate의 평균, 표준편차, 95% 신뢰구간 산출. 박스플롯 및 히스토그램으로 분포 확인. 천장/바닥 효과 점검. 두 집단의 읽기 소요 시간이 유의하게 다르지 않은지 확인(조작 검증).

2
정규성 검정 (Normality)

Shapiro-Wilk 검정 — 집단별·시점별 각각 실시 (n < 50에서 적합). p > 0.05 → 정규성 가정 유지 → 독립 t-검정 진행. p ≤ 0.05 → 비모수 대안 적용 (§6-B).

3
[주 분석] 독립 t-검정 — H0₁, H0₂

T1 점수: A그룹 vs B그룹 — 독립 t-검정 (단측, α=0.025)
T2 점수: A그룹 vs B그룹 — 독립 t-검정 (단측, α=0.025)
등분산 가정: Levene 검정 → 위반 시 Welch's t-검정 적용
효과 크기: Cohen's d (소=0.20, 중=0.50, 대=0.80)

4
[탐색] 망각량 비교 — H0₃

retention_drop(Δ = T1 − T2): A그룹 vs B그룹 — 독립 t-검정 (단측, α=0.05)
또는 retention_ratio: Mann-Whitney U (정규성 위반 시)
B그룹의 Δ가 A그룹보다 유의하게 작으면 → 개념도 조건이 파지에 유리

5
[보조] 집단 내 반복 측정 — T1 vs T2 변화

각 집단 내: T1 → T2 점수 변화 — 대응 t-검정
양 집단 모두 T2가 하락한다면(망각): 얼마나 하락하는지 비교
이는 H0₃와 같은 방향의 분석이지만 집단 내 반복 측정으로 보강

6
[탐색] 개념도 복잡도 상관 — H0₄ (B그룹 한정)

Pearson r(노드 수, T2_rate), r(엣지 수, T2_rate), r(수정 횟수, T2_rate)
95% 신뢰구간 함께 보고. 정규성 위반 시 Spearman ρ.

7
[보조] 설문·확신도 기술통계 및 집단 비교

설문 리커트 점수: 집단별 평균·SD 기술통계, 독립 t-검정 또는 Mann-Whitney. 확신도-정확성 보정(calibration) — Overconfidence index = mean(confidence|오답) − mean(confidence|정답).

§6-B 정규성 위반 시 비모수 대안

모수 검정비모수 대안적용 조건
독립 t-검정 Mann-Whitney U 검정 집단 간 T1/T2/Δ 비교
대응 t-검정 Wilcoxon 부호순위 검정 집단 내 T1 → T2 변화
Pearson r Spearman ρ 개념도 복잡도 상관

§6-C 정규성 검정 의사결정 트리

Shapiro-Wilk 검정 실시 (집단별·시점별)
p > 0.05 (정규성 충족)
독립 t-검정 (Levene 검정 후 등분산 여부에 따라 Student's/Welch's)
p ≤ 0.05 (정규성 위반)
Mann-Whitney U (집단 간) / Wilcoxon (집단 내) / Spearman ρ (상관)

현재 구현 상태
