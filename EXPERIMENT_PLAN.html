1. 실험 설계 개요

본 실험은 2(개념도 조건: 유/무) × 2(시점: 사전/사후) 혼합 설계(Mixed Design)를 채택한다.

2. 최소 표본 수 결정

정규분포 가정 성립 조건

중심극한정리(CLT)에 의해 집단 내 n ≥ 15이면 표본 평균의 표집분포가 정규분포에 근사한다. 혼합 설계 ANOVA에서는 집단당 최소 15명이 일반적 권고 하한선이다.

검정력 분석 (G*Power 기준)

  • 유의수준 α = 0.05
  • 목표 검정력 1−β = 0.80
  • 효과 크기 Cohen's f = 0.25 (중간 효과, 사회과학 관례)
  • 반복 측정 간 상관 ρ = 0.50 (보수적 추정)
  • 집단 수 = 2, 측정 시점 수 = 2

3. 귀무가설 및 대립가설

점수는 정답률(%)로 표준화한다: score_rate = (획득점수 / 최대점수) × 100

주요 분석 지표는 Δ = post_rate − pre_rate (사전→사후 개선량)이다.

H1 — 필터링 인터페이스 효과 (전원 대상)

귀무가설 H0₁
사전-사후 점수 변화 없음

μpost = μpre
AI 요약 검토 개입은 오류 탐지 점수에 유의한 변화를 일으키지 않는다.

대립가설 H1₁
사후 점수가 사전보다 높음 (단측)

μpost > μpre
AI 요약 검토 개입 후 오류 탐지 점수가 유의하게 향상된다.

H2 — 개념도 도구 효과 (집단 간 상호작용)

귀무가설 H0₂ 핵심
집단 × 시점 상호작용 없음

(μpost,G1 − μpre,G1) = (μpost,G2 − μpre,G2)
개념도 유무와 관계없이 사전→사후 개선량은 동일하다.

대립가설 H1₂
집단 1의 개선량이 더 큼 (단측)

ΔG1 > ΔG2
개념도를 사용한 집단이 사용하지 않은 집단보다 더 크게 향상된다.

H3 — 개념도 복잡도와 학습 효과 (탐색적)

귀무가설 H0₃
개념도 복잡도와 개선량 무상관

ρ(노드 수, Δ) = 0
개념도의 정교성(노드·연결 수)은 점수 개선량과 관련이 없다.

대립가설 H1₃
복잡도↑ → 개선량↑ (양측)

ρ(노드 수, Δ) ≠ 0
개념도를 더 정교하게 작성한 참가자일수록 점수 개선량이 크다.

4. 유의수준 설정

가설검정유의수준 α근거
H0₁ (필터링 효과) 대응 t-검정 (단측) 0.05 주요 가설, 단측 검정
H0₂ (상호작용) 혼합 ANOVA → 단순 효과 0.05 핵심 가설
H0₃ (복잡도 상관) Pearson r (집단 1 only) 0.05 탐색적, 단일 검정
사후 다중 비교 Bonferroni 교정 0.05 / k 검정 수(k)에 따라 교정
단측 vs 양측: H0₁과 H0₂는 방향성 예측이 명확하므로 단측 검정(one-tailed) 적용. H0₃는 방향 불확실(정교한 개념도가 오히려 부담일 수 있음)하므로 양측 검정.

5. 정량화 지표 및 측정 변수

주요 종속변수 (Primary DVs)

score_rate(%) = (획득점수 / 최대점수) × 100
  최대점수: pre/post = 11점, filtering = 8점

Δ = post_rate − pre_rate   ← 핵심 분석 단위
improvement_ratio = Δ / (100 − pre_rate)   ← 개선 여지 대비 실제 개선

보조 종속변수 (Secondary DVs)

변수측정 방법분석 목적
판단 확신도 (confidence) 1–5 Likert, 문장별 측정 확신도-정확성 보정 (calibration) 분석
응답 시간 (ms) 문장 노출 ~ 제출 버튼 클릭 pre→post 처리 효율 변화
오류 유형별 탐지율 direction / causality / scope / limitation 별 정답률 어떤 오류가 더 취약한지
개념도 복잡도 (집단 1) 노드 수, 엣지 수, 수정 횟수, 소요 시간 Δ와의 상관 (H0₃)
설문 리커트 (fq1–5, cq1–5) 5점 Likert × 5–10문항 주관적 유용성·부담감 기술통계

확신도-정확성 보정 지수 (Calibration)

overconfidence_index = mean(confidence | 오답) − mean(confidence | 정답)
  양수: 틀렸을 때 더 확신 → 자동화 편향 의심
  0에 가까울수록 보정 양호

6. 통계 검증 방법 (분석 순서)

1
기술통계 (Descriptive Statistics)

집단별·시점별 score_rate의 평균, 표준편차, 95% 신뢰구간 산출. 박스플롯으로 분포 확인. 천장/바닥 효과(ceiling/floor effect) 점검.

2
정규성 검정 (Normality Test)

Shapiro-Wilk 검정 (n < 50에서 적합) — 집단별·시점별 각각 실시. p > 0.05 → 정규성 가정 유지 → 모수 검정. p ≤ 0.05 → 비모수 대안 적용 (§6-B).

3
[모수] 2×2 혼합 ANOVA — 주 분석

요인 A (between): 개념도 조건 (집단 1 vs 2)
요인 B (within): 시점 (pre vs post)
핵심 검정: A×B 상호작용 효과 → F(1, 28), α=0.05
효과 크기: partial η² (소=0.01, 중=0.06, 대=0.14)
구형성 가정: Mauchly 검정 → 위반 시 Greenhouse-Geisser 교정

4
[모수] 사후 단순 효과 분석 (Simple Effects)

ANOVA 상호작용 유의 시:
· 집단 1 내: pre vs post — 대응 t-검정 (단측)
· 집단 2 내: pre vs post — 대응 t-검정 (단측)
· 개선량(Δ) 비교: G1 vs G2 — 독립 t-검정 (단측)
Bonferroni 교정: α = 0.05/3 ≈ 0.017

5
[모수] 개념도 복잡도 상관 분석 (집단 1)

Pearson 상관계수 r(노드 수, Δ), r(엣지 수, Δ), r(수정 횟수, Δ)
효과 크기: r (소=0.10, 중=0.30, 대=0.50)
95% 신뢰구간 함께 보고

6
[보조] 오류 유형별 탐지율 비교

direction / causality / scope / limitation 각 유형별 정답률 산출. 집단 × 유형 상호작용: 반복측정 ANOVA (시점별 구분). 어떤 오류 유형이 개념도로 가장 개선되는지 탐색.

7
[보조] 확신도·응답시간 분석

확신도: 집단×시점 혼합 ANOVA (score_rate와 동일 구조)
응답시간: 로그 변환 후 동일 구조 분석 (응답시간은 정규분포 미준수 경향)
과신 지수(overconfidence_index): 집단 간 독립 t-검정

§6-B 정규성 위반 시 비모수 대안

모수 검정비모수 대안적용 조건
혼합 ANOVA Aligned Rank Transform (ART) ANOVA 정규성 위반, 혼합 설계 유지 필요 시
대응 t-검정 Wilcoxon 부호순위 검정 집단 내 pre-post 비교
독립 t-검정 Mann-Whitney U 검정 집단 간 Δ 비교
Pearson r Spearman ρ 개념도 복잡도 상관

§6-C 정규성 검정 의사결정 트리

Shapiro-Wilk 검정 실시
p > 0.05 (정규성 충족)
혼합 ANOVA → 대응/독립 t-검정 → Pearson r
p ≤ 0.05 (정규성 위반)
ART ANOVA → Wilcoxon / Mann-Whitney → Spearman ρ

결과 판단 기준 요약

가설기각 조건해석
H0₁ (필터링 효과) t-검정 p < 0.05 (단측), d > 0.20 AI 요약 검토 인터페이스가 오류 탐지력 향상에 기여
H0₂ (상호작용) ANOVA 상호작용 p < 0.05, partial η² > 0.06 개념도 도구가 추가적 학습 효과를 만들어냄
